# 로컬 실행 가이드

## 전제 조건

| 항목 | 기준 |
|---|---|
| OS | Ubuntu 기준 |
| Java | 17 |
| Node.js | Create React App 실행 가능 버전 |
| DB | Docker MySQL |
| Backend port | 기본 `8085` |
| Frontend port | 기본 `3000` |

## DB

로컬 개발 DB 이름은 `timetodo`를 사용한다.

현재 backend는 `backEnd/.env` 값을 읽어 DB에 연결한다.

```properties
DB_HOST=localhost
DB_PORT=3306
DB_NAME=timetodo
SERVER_PORT=8085
SPRING_PROFILES_ACTIVE=local
DB_USERNAME=...
DB_PASSWORD=...
OPENAI_API_KEY=...
CORS_ALLOWED_ORIGINS=http://localhost:3000
COOKIE_SECURE=false
COOKIE_SAME_SITE=Lax
```

실제 credential과 API key는 문서나 Git에 기록하지 않는다. 필요한 키 목록은 `backEnd/.env.example`을 기준으로 확인한다.

DB schema는 Flyway migration으로 관리한다.

- migration 위치: `backEnd/src/main/resources/db/migration`
- 초기 schema: `V1__init_schema.sql`
- local profile은 `spring.jpa.hibernate.ddl-auto=validate`를 사용한다.
- 기존 로컬 DB는 `spring.flyway.baseline-on-migrate=true`로 baseline 처리된다.
- 새 DB에서는 Flyway가 `V1__init_schema.sql`을 적용한 뒤 Hibernate가 schema 정합성을 검증한다.

## Backend 실행

```bash
cd backEnd
bash ./mvnw spring-boot:run
```

성공 기준:

- `local` profile 활성화
- MySQL 연결 성공
- Tomcat `8085` 기동

## Frontend 실행

```bash
cd frontEnd
npm run start
```

프론트는 기본적으로 CRA proxy와 공통 axios client를 사용한다.

- 기본 API base URL: 빈 문자열
- override: `REACT_APP_API_BASE_URL`

## 검증 명령

Backend:

```bash
cd backEnd
bash ./mvnw test
```

Frontend:

```bash
cd frontEnd
npm run build
```

현재 프론트 build는 ESLint warning 없이 성공한다.

## 기본 API 점검

로그인 전 보호 API:

```bash
curl -i http://127.0.0.1:8085/api/user/me
curl -i http://127.0.0.1:8085/api/tasks
```

기대 결과:

- `401 Unauthorized`

로그인 후:

```bash
curl -c /tmp/timetodo_cookies.txt -b /tmp/timetodo_cookies.txt \
  -H "Content-Type: application/json" \
  -X POST http://127.0.0.1:8085/api/user/login \
  -d '{"username":"...","password":"..."}'

curl -b /tmp/timetodo_cookies.txt http://127.0.0.1:8085/api/user/me
```

기대 결과:

- 로그인 `200`
- `/api/user/me` `200`

## 주의 사항

- DB schema 변경은 새 Flyway migration 파일로 추가한다.
- 현재 인증 구조는 Spring Security session 기반이다.
- DB 초기화가 필요한 경우 기존 로컬 데이터가 삭제될 수 있으므로 작업 전 확인한다.
