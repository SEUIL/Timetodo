# 1차 개선 기록

## 2026-05-28 인증/보안 최소 개선

### 변경 범위
- 로그인 실패 시 서버 오류 대신 `401 Unauthorized`를 반환하도록 수정.
- 회원가입 시 비밀번호를 평문 저장하지 않고 BCrypt로 해시 저장하도록 수정.
- credential 허용 CORS에서 wildcard origin을 제거하고 `.env` 기반 허용 origin 설정으로 전환.
- 로그인 쿠키의 `HttpOnly`, `SameSite`, `Secure` 설정을 application property와 `.env`에서 조정 가능하게 변경.
- 기존 `timetodo` DB는 초기화 후 Spring Boot `ddl-auto=update`로 schema를 재생성.

### 검증 결과
- `bash ./mvnw -DskipTests package`: 성공.
- DB 초기화 후 backend 기동: 성공.
- `POST /api/user/signup`: `200`.
- 잘못된 비밀번호 `POST /api/user/login`: `401`.
- 정상 비밀번호 `POST /api/user/login`: `200`, `Set-Cookie` 반환 확인.
- DB 저장 비밀번호: 원문과 다르고 길이 60의 BCrypt 형식 prefix 확인.
- 허용 Origin `http://localhost:3000` CORS preflight: `200`.
- 비허용 Origin CORS preflight: `403`.

### 남은 리스크
- `userId` 쿠키를 신뢰하는 API 구조는 아직 남아 있음. 다음 단계에서 session/JWT 또는 서버 측 인증 컨텍스트로 교체 필요.
- Task/Calendar 수정·삭제 owner 검증은 아직 미해결.
- frontend API base URL 정리는 별도 단계로 남아 있음.
