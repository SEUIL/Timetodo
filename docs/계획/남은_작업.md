## P1. 인증 구조 고도화

현재는 `HttpSession` 기반 최소 인증 구조다.

완료된 것:

- 서버가 `userId` 쿠키를 신뢰하지 않도록 변경.
- 로그인 성공 시 세션에 사용자 ID 저장.
- `/api/user/me` 추가.
- 보호 API에서 현재 사용자 확인.

남은 선택지:

1. 현재 `HttpSession` 구조를 유지하고 예외 처리, logout, cookie 정책을 보강한다.
2. Spring Security form/session 기반으로 전환한다.
3. JWT 기반으로 전환한다.

권장:

- 포트폴리오와 유지보수 관점에서는 Spring Security session 기반 전환이 적절하다.
- JWT는 배포/모바일/외부 API 요구가 생긴 뒤 결정해도 된다.

## P1. Entity 관계 필드명 정리

현재 `TaskEntity.userId`, `TaskEntity.categoryId`, `CalendarEntity.userId`, `CalendarEntity.categoryId`는 이름은 ID처럼 보이지만 실제 타입은 Entity다.

문제:

- DTO 변환 시 혼동 증가.
- Repository method 이름이 어색해짐.
- 장기적으로 API 응답과 Entity 경계가 흐려질 수 있음.

목표:

- `userId` -> `user`
- `categoryId` -> `category`
- `reminderId` -> `reminders`

주의:

- JPA mappedBy, repository method, service 변환 로직을 함께 바꿔야 한다.
- DB column 이름 유지 여부를 결정해야 한다.

## P1. Task/Calendar API 계약 정리

현재 API는 기존 프론트 호환을 위해 아래 형태를 유지하고 있다.

- `POST /api/task/add`
- `GET /api/task/find`
- `PUT /api/task/update?categoryId=...`
- `DELETE /api/task/delete`
- `POST /api/calendar/add`
- `GET /api/calendar/find`
- `PUT /api/calendar/update?categoryId=...`
- `DELETE /api/calendar/delete`

목표:

- RESTful path로 정리.
- ID는 path variable로 이동.
- delete body 제거.
- request/response DTO 명확화.

예상 형태:

```text
POST   /api/tasks
GET    /api/tasks
PUT    /api/tasks/{taskId}
PATCH  /api/tasks/{taskId}/status
DELETE /api/tasks/{taskId}

POST   /api/calendars
GET    /api/calendars
PUT    /api/calendars/{calendarId}
DELETE /api/calendars/{calendarId}
```

## P2. AI 기능 책임 분리

현재 `OpenAIService`는 다음 책임이 섞여 있다.

- OpenAI HTTP 호출
- AI 응답 parsing
- Task/Calendar/Reminder 생성
- log 저장
- 사용자 선택 흐름 처리

분리 후보:

- `OpenAiClient`
- `AiResponseParser`
- `AiCommandService`
- `ScheduleCommandService`
- `AiLogService`

목표:

- OpenAI 응답 형식이 바뀌어도 도메인 생성 로직이 같이 깨지지 않게 한다.
- AI 기능 테스트를 API 호출 없이 작성 가능하게 한다.

## P2. 프론트 warning 정리

현재 `npm run build`는 성공하지만 unused 변수 warning이 남아 있다.

대표 항목:

- `TodayCalendar.js`: `dayGridPlugin`, `isDetailModalOpen`, `closeDetailModal`
- `Login.js`: `error`
- `Profile.js`: `DarkModeSwitch`, `toggleDarkMode`

- 실제로 쓰지 않는 코드 제거.

- build warning 0개로 정리.
